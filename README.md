- Desafio Técnico

Repositório destinado à implementação das soluções propostas em um desafio técnico para uma vaga na área de desenvolvimento de software.

- Tecnologias utilizadas

* Java
* Maven
* Gson
* Eclipse IDE

- Execução

Cada solução está organizada em seu próprio pacote Java e possui uma classe Main para execução:

* desafio1.Main
* desafio2.Main
* desafio3.Main

Os arquivos JSON utilizados como entrada estão organizados na pasta dados.
